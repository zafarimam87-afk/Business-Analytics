HOW TO ADD AHRAR'S PHOTOS
==========================

1. Save Ahrar's photos into THIS folder (photos/ahrar/)
2. Name them exactly like this:
   - photo1.jpg
   - photo2.jpg
   - photo3.jpg
   ... up to photo8.jpg

3. Supported formats: .jpg, .jpeg, .png, .webp

4. Reload the website in your browser and the photos will appear automatically
   in the "About Ahrar" section!

TIP: To get photos from Facebook:
   - Open Ahrar's Facebook profile on a browser
   - Right-click each photo > "Save image as..."
   - Save them as photo1.jpg, photo2.jpg etc. in this folder
