# 🚀 Ahrar's Learning Galaxy

An interactive learning platform built especially for **Ahrar Zafar** (age 7) — a curious explorer who loves space science, quantum physics, animals, karate, and drawing.

## 🌟 Live site

👉 **https://zafarimam87-afk.github.io/ahrar-learning-galaxy/**

## 📚 Modules

| Module | What's inside |
|--------|---------------|
| 👦 About Ahrar | Profile, photo gallery, fun facts |
| 🎨 My Drawings | Gallery of Ahrar's artwork |
| 🐍 Python Coder | 8 gamified Python lessons with live in-browser code runner (Skulpt) |
| 🔢 Math Adventure | Math Blitz, Survival Mode, Times Tables, quizzes |
| 🔬 Science Lab | 12 animal cards, flashcards, quizzes, videos |
| 🚀 Space Explorer | Animated solar system, 8 planet facts, mind maps |
| 🥋 Karate Dojo | 8-belt path, daily practice tracker, 10 techniques |
| ✏️ Drawing Studio | 6 step-by-step tutorials, free drawing canvas |

## ✨ Features

- **XP system, levels, and achievements** — gamified learning that saves progress in your browser
- **Quiz engine, flashcard engine, mind map engine** — reusable learning tools
- **Animated solar system** built with HTML5 Canvas
- **In-browser Python runner** powered by Skulpt
- **Free drawing canvas** with pen, eraser, fill tools and PNG export
- 100% client-side — no backend, no tracking, no ads

## 📂 Adding photos and drawings

- **More photos:** save as `photo19.jpg`, `photo20.jpg`… in `photos/ahrar/`
- **New drawings:** save as `drawing1.jpg`, `drawing2.jpg`… in `drawings/`
- Commit and push — they appear automatically in the gallery

## 🛠️ Built with

Pure HTML5, CSS3, vanilla JavaScript. No frameworks, no build step.
